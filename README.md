Employee Attrition & HR Analytics Dashboard

Project Overview

This project focuses on analyzing employee attrition patterns and workforce performance using Power BI. The dashboard helps HR teams identify key factors influencing employee turnover and supports data-driven workforce planning and retention strategies.

Business Problem

Employee attrition can significantly impact productivity, hiring costs, and organizational performance. The objective of this project is to identify attrition trends across departments, experience levels, salary bands, and employee satisfaction metrics.

Tools Used

- Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

Dataset Features

- Employee ID
- Age
- Gender
- Department
- Salary
- Experience
- Performance Rating
- Satisfaction Score
- Work-Life Balance
- Overtime Status
- Attrition Status

Key KPIs

- Employee Attrition Rate (%)
- Average Employee Salary
- Average Employee Experience
- Employee Satisfaction Index

Dashboard Visuals

- Department-wise Employee Attrition
- Workforce Gender Distribution
- Attrition Trend by Employee Experience
- Employee Satisfaction vs Performance Heatmap
- Overtime Impact on Attrition
- Interactive Slicers for Department, Gender, and Overtime Status

Key Insights

- Customer Service department recorded the highest attrition.
- Employees working overtime showed a higher tendency to leave.
- Higher salary bands demonstrated stronger retention.
- Employee satisfaction showed a strong relationship with attrition behavior.

Business Impact

The dashboard enables HR managers to:

- Monitor workforce trends.
- Identify high-risk employee segments.
- Improve employee retention strategies.
- Support workforce planning decisions.
